# Agent Delivery Report: free sample

Makes your coding agent end every task with a clear report.

## Claude Code
Copy `SKILL.md` to `.claude/skills/delivery-report/SKILL.md` in your repo (or `~/.claude/skills/delivery-report/`).

## Codex CLI
Paste the body of `SKILL.md` into `AGENTS.md` at the root of your repo (or `~/.codex/AGENTS.md`).

## Cursor
Save `SKILL.md` as `.cursor/rules/delivery-report.mdc` and set it to always apply.

`delivery-report-template.md` is the report format, if you want to use it by hand or in PR descriptions.
